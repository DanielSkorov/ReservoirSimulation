# Основы линейной алгебры

Понимание операций над векторами, матрицами и их преобразованиями необходимо для изучения основ композиционного гидродинамического моделирования, поскольку смысловыми единицами зачастую выступают параметры, представляющие собой векторы (как, например, *компонентный состав* в PVT-моделировании, *скорость течения* в гидродинамике или *вектор напряжения* в геомеханике). Данная глава не претендует на полноценный курс о линейной алгебре, а является кратким изложением избранных понятий, свойств и теорем, необходимых для дальнейшего изучения композиционного гидродинамического моделирования.
